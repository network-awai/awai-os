# Hosted nonempty-root streamed writer process-kill proof — 2026-11-15

The adjacent hosted JVM probe first publishes a 1 MiB block and ref, then replaces that nonempty root with 18 deterministic 1 MiB blocks staged in two Forest archives. It kills an independently launched writer at seven file/WAL/root observer boundaries and opens the result in a fresh process. Forest half-write and rename, WAL half-write and rename, and root half-write recovered the old ref and original block. Root rename and directory sync recovered the new ref and all 18 verified blocks, while preserving the original block. All seven passed in 43.36 s; parent peak RSS 292,180 KiB. The old block remained separately accessible even after the new ref was published.

The test is a process-kill check in one guest, not a host-cache-loss, power-failure, distributed fencing or production authorization proof.
