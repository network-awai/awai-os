# Hosted governed receipt adapter — 2026-11-15

`atomic-stream-governed-receipt-adapter` adapts Kotobase's published atomic receipt sink to the existing file-staged Forest writer. It accepts the sink's exact `{:receipt :prepared :nonce}` input, clones marker bytes, passes the owned nonce to the required semantic closure verifier, and exposes both receipt-ref and nonce-ref readers. The underlying writer publishes the group, receipt ref and absent nonce ref under one local root. The caller must authenticate the request, derive/verify its nonce scope and marker, verify the complete closure and exclude concurrent GC. This is a hosted API and is not wired into a deployed service or a Native execution path.

The local Babashka two-Pack proof uses the pinned actual macOS ARM Forest tool `e5fb23076a46c055142b3dbf3efa1ad5a68532d14419ad9994785986719b205f`. It rejects a missing nonce and incorrect fixture marker semantics without changing root, publishes 19 blocks across multiple Packs, verifies both ref readers and the group/receipt/nonce single frame, rejects replay, and recovers all bytes in a fresh process with the tool path absent. The marker's semantic verifier is a fixture; canonical Kotobase marker checks are exercised by the separate GiB oracle.
