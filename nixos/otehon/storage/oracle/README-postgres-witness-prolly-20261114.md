# Witnessed persistent Prolly and Datalog — hosted JVM oracle

On macOS 26.4 arm64, OpenJDK 21.0.1, Clojure CLI 1.12.5.1654, PostgreSQL 14.19 and the pinned Forest tool, `postgres_witness_prolly_check.sh` ran the actual adapted Kotobase Prolly engine and Datalog over the explicitly witnessed Otehon block/ref backend. Its host-supplied closure callback uses the bounded Kotoba IPLD decoder and a graph walk limited to 256 blocks, 32 MiB, depth 64 and 4,096 edges; per-block decoder bounds are also applied. The database is a newly initialized task-owned Unix-socket-only cluster and is stopped at the end.

Two transactions published distinct physical roots. A stale expected ref was refused. After clean database restart, a fresh JVM recovered the second root, traversed 12 blocks and 15 links, and returned `alpha` for the old snapshot and `as-of 1`, and `beta` for the current query. An injected omitted descendant and a one-block closure limit were refused without changing the root or witness. Physically withholding a Forest archive caused ref reading to fail, without changing the witness; the archive was restored. The omitted-descendant test is a callback injection, not a physically missing individual block.

The exact Forest tool SHA-256 is `e5fb23076a46c055142b3dbf3efa1ad5a68532d14419ad9994785986719b205f`. The local run verified all 200 files in `prolly_forest_writer_inputs.json` under `.agent-output/policy-forest/classpath`; bounded decoder overrides were separately verified as `b597c060b56766a56d94f367ed1bc7c59ec8d086a93ac85037867bb701ec33ab` (CBOR) and `2ebb52cd066e71bc43446dfe62ceaab6569e7b59a3c93b10bd37f266bc9450e8` (IPLD), from the pinned draft described in `README-kotobase-bounded-closure.md`. An earlier exploratory run used `.agent-output/positioned/classpath`, where three files did not match that older manifest, including two SHA-2 sources loaded by the JVM. Its result was retained but is not used as the pinned evidence; the fresh-cluster run above used the verified classpath. No new dependencies were downloaded.

To repeat, from the repository root with the already prepared classpaths and pinned tool, pass an unused absolute base directory, an unused short absolute Unix-socket directory, and the tool path to `postgres_witness_prolly_check.sh`. It verifies input hashes, retains artifacts, and stops only its own cluster. It runs a local hosted JVM oracle; it is not a Native build or runtime fallback, and is not a required CI gate.

The closure verifier is supplied by the experiment, not installed as a product default. The 32 MiB graph limit is checked after a provider returns each block; it does not bound provider allocation. Blinding and encryption are deterministic identity fixtures. A DB primary on the same host and a local writer lock do not prove an independent witness, rollback resistance, distributed fencing, physical power loss or OS cache loss. There is no signed basis, real policy/receipt or production qualification in this result. Block batch and ref publication are separate witnessed commits; a failed ref update can leave an orphan group.
