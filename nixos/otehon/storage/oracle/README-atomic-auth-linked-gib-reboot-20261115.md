# Atomic receipt, authenticated fixture authority and linked GiB after reboot — 2026-11-15

On the dedicated Ubuntu ARM guest, Otehon source `5ca70469669cb72fa56ad68dccfb5b6ff32199c7` and the pinned Kotobase authenticated linked-GiB fixture were composed by `atomic_authenticated_linked_gib.clj` (SHA-256 `67c51a35db412a084827a1dfd938fda46a2e208a5d4592bafe354bcd9701fdcd`). The wrapper checks the fixture SHA and substitutes the bounded atomic receipt adapter. The fixture writes and verifies a persisted authority decision with a scoped Ed25519 attestation, refuses bad signature, absent key and wrong tenant, verifies every chunk of the separate guest-created 1 GiB file, and publishes three linked receipt records. The fixture Datalog result is one row.

After guest stop/start, boot ID changed from `dd1c1347-a30a-47ad-8dba-fefcc73b91d4` to `b66472d5-2b4c-4330-82ab-e63986057c5d`. The first task-data read used a fresh JVM and nonexistent writer tool; it authenticated the decision commit and location, checked all 1,024 chunks against SHA-256 `1f7e0c0d3fefe5579e556a04f7796b7de01278916e49a6d31df864e16adf1708`, verified the three records, and rejected altered authority signature, tenant, location and request. The 162-file source/store manifest matched after readback. The receipt store's last WAL frame was `:put-many` with exactly one group key and one ref key. Guest/host evidence archive SHA-256 `f0734dc948275988cb6c5e34801ad7f95fe4ec2d299d69c81a2a893c8e0efd79`.

The issuer, keys, registry, policy and clock are fixtures and the attestation is in a fixture sidecar. This is not production authority or rollback resistance. File, authority, nonce and receipt are separate transactions/stores; the location uses a CID string rather than an IPLD link, and the Datalog row is unrelated to the file. The receipt batch is bounded to 32 MiB; the GiB file was not atomically published with it. This was hosted JVM and emulated x86 Forest, with guest OS cache loss only, not Native, host cache loss, independent nodes or physical power loss. This experiment is not a CI gate.
