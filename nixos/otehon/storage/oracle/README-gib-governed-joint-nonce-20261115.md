# Hosted governed 1 GiB receipt and nonce probe — 2026-11-15

This is a local, fixture-authority experiment, not a Native or production qualification. `gib_governed_joint_nonce.clj` pins and extends the existing hosted governed probe by SHA-256; its fixture, classpath bundle, commands, output and original 1 GiB input are retained under this worktree's `.agent-output/product-ports-gib-host-20261115/`. The probe requires those inputs; the committed script alone is not a self-contained reproduction. It used the Awai source at `52101ac` and the Kotobase nonce-store source at `224d1cb` (source SHA-256 `da81f947b00a32f86a2619b905062c40baa4da711e6de1b300da18137b66e929`). The macOS ARM Forest tool had SHA-256 `e5fb23076a46c055142b3dbf3efa1ad5a68532d14419ad9994785986719b205f`. Write/read command wrappers had SHA-256 `cae485c377db6f27418ddaaf564d86a3438a33ce75bcde7b74b4dbc26bc984f9` and `d7989f6cb8e92379b41468ea213880abe6eb73f3808e904c3ae6b7a446fa6a34` respectively. The actual fixture is predominantly zero-filled and is not representative of general compression performance.

The fixture uses the governed execution path with a non-reserving nonce availability check, and publishes a prepared canonical marker with each receipt and its Forest group through the same local root. The signed Prolly/policy basis and the 1,024 chunks of the logical file were included in each publication. The allow and deny publications are **separate** local transactions. Inspecting the root's WAL found two `put-many` frames, each containing exactly one group, receipt reference, and nonce reference; the two groups each contained 61 Forest files. The governed replay of the allow nonce was refused without another query evaluation or root change. The fixture's signed basis, policy checks, allow/deny receipts and original file SHA-256 `1f7e0c0d3fefe5579e556a04f7796b7de01278916e49a6d31df864e16adf1708` were verified.

A fresh JVM read the published store with the original source and Forest writer paths unavailable. Both nonce replays were refused without changing the root, and receipt, policy, signature, file bytes and missing-request rejection checks passed. Write elapsed time was 155.38 s with maximum resident set 949,518,336 bytes; fresh read was 47.61 s with maximum resident set 610,762,752 bytes. These are one hosted measurement each, include verification and other fixture work, and are not throughput benchmarks.

The nonce preflight does not reserve it: concurrent requests may both evaluate, although only a successful under-lock commit can publish a result. The host must bind the nonce marker, identity and request correctly; this test supplies fixture authority and keys. It does not establish production authorization, independent-node durability, Native I/O, OS cache loss, power-loss recovery, or transactions spanning separate stores. Those remain separate work.
