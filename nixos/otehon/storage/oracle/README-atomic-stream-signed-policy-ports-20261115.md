# Signed basis and persisted policy through product streamed ports — 2026-11-15

On macOS arm64, `atomic_stream_signed_policy_ports.clj` used the product `publish-atomic-stream-ports!` operation to write 18 deterministic random 1 MiB blocks, an actual Prolly snapshot containing a policy and a file/block reference, and a signed logical-basis proof into one Forest catalog group. The group contained at least two Packs and shared one `:put-many` WAL frame with its ref. The closure verifier derived the checkpoint, verified the Ed25519 signature, recovered the policy from the snapshot, ran protected Datalog allow/deny queries, and checked all 18 blocks. A separate JVM with the writer unavailable reopened the ref and repeated the checks. Proof CID was `bafkreibnchvoxcyf4ulqwxop4fki455k77o3imiw63cagxne3xa27u7pyu`.

This is a bounded hosted integration experiment. Ed25519 seed, issuer, clock/location trust, visibility capabilities, blinding and encryption are fixtures; the proof is not a deployed key registry or production trust decision. It does not publish a durable execution receipt, use Native, test concurrent GC or cross-store atomicity, or establish OS-cache loss or physical power-loss durability. It is not a Native gate or fallback.
