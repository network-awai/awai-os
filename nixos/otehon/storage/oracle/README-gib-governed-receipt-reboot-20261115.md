# Hosted governed GiB receipt reboot experiment — 2026-11-15

The adjacent pinned hosted composition opens the signed GiB Prolly basis and persisted `:file/` read policy of `atomic_gib_policy_prolly.clj`. Kotobase `governed-execution` binds a request and signed execution manifest to that physical root and policy CID. The signed fixture location points to the signed-basis CID, physical root and policy. A real Dango fixture decision supplies allow or deny, and the evaluator executes the protected Datalog query against the recovered snapshot. The allowed row contains the actual GiB manifest CID; its computed result root is checked against the execution receipt. A denied decision calls no evaluator. Both signed receipts, requests and manifests are committed and read back through the hosted Forest/ref adapter in a separate receipt store.

After dedicated guest stop/start, a fresh reader with nonexistent source-file and Forest-writer paths reopened both stores, checked both receipts and their signatures, the request/manifest contract, signed basis and policy binding, rejected a missing request block, and rechecked the file's 1,024 chunks against SHA-256 `1f7e0c0d3fefe5579e556a04f7796b7de01278916e49a6d31df864e16adf1708`. Boot ID changed and all 93 recorded source/store files matched their pre-reboot hashes. One write run took 10.83 s / 494,340 KiB RSS; the postboot receipt plus full-file read took 22.19 s / 533,448 KiB RSS. Mostly-zero synthetic data and uncontrolled host cache mean these times are not production performance.

The data and receipt stores are separate: no atomic transaction across them is proven. The issuer and Dango seeds, execution signer, clock, location record, nonce callback and schema are fixtures; this is not production identity, nonce replay protection, independent witness, distributed fencing, or product-wide enforced admission. A denial is signed and retained, but no external authority receipt is linked by this probe. Guest restart loses guest cache, not host cache; Native, live AwaiVol, physical power loss and remote durability remain open. Do not substitute this evidence for those requirements.
