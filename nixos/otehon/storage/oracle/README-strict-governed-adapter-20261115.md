# Bound governed receipt publication — 2026-11-15

The opt-in bound mode of the hosted streamed governed receipt adapter now writes the exact group/catalog binding with the receipt ref and nonce ref in one WAL frame. Its final closure verifier receives only blocks in the candidate group: it cannot silently satisfy a dependency from an older group. Receipt-ref readback opens that exact bound group; nonce-ref readback requires the marker to be in that group and rejects a generation mismatch. Callers must authenticate identity, validate marker semantics and the full closure, and exclude concurrent mutation and GC during readback. A returned handle is not pinned against later mutation. Existing unbound entry points remain available, and legacy refs do not become bound without explicit migration.
