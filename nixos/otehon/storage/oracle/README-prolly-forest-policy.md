# AWAI-174: Dango and policy over persisted Forest — 2026-11-13 UTC

This local hosted reference oracle connects existing Dango Ed25519 chain
verification, the existing `kotobase-peer.policy` reader policy and the actual
Prolly/Datalog engine to the Otehon positioned IPLD Forest catalog. It is a
cross-layer experiment, not a new authorization format or production adapter.

The fixture contains 18 CID-addressed blocks generated by the AWAI-174 Prolly
policy fixture. The 9,490-byte Forest archive is SHA-256
`0ea6a8f7b6d2086a2a6565f9a787fcac316d7bb18b5856cdb6bf935df477b0ed`;
the Prolly root is
`bafyreic73cz5ww6pbthvvyz62szwjs25afgaqr2a6va4xwl344bmfw4iri`.
A hosted Babashka process publishes it through the real Otehon WAL/root and
ends. A separate JVM reference process recovers it and reads data via the
catalog's verified positioned frame reads. It loads the policy protecting
`:chunk/` from the Prolly snapshot and evaluates the four-clause join.

The test uses deterministic **test keys** to sign a real Dango chain whose
read capability resource contains exactly the selected Prolly root. The
existing verifier checks Ed25519 signatures, the presentation seal, target,
expiry and an explicitly supplied revoked-CID set. The allowed decision sees
the expected row; wrong basis, expiry, invalid seal and revoked capability
produce no rows. Result reasons: `:granted`, `:dango/not-covered`,
`:dango/expired`, `:dango/bad-seal`, `:dango/revoked`. Across policy and query
reads, 23 positioned frames / 24,388 compressed bytes were read, with repeated
frames included. Corrupted and missing task-owned archive copies were refused
before query. This is not a cold-cache or throughput measurement.

Reproduce using Babashka 1.12.218, Clojure CLI 1.12.5.1654 and the adapted
AWAI-174 v6 reference classpath documented in Kotoba PR #1334. The classpath,
fixture, source and original block hashes are in `prolly_forest_policy_inputs.json`.
No dependencies were downloaded for the run. For a new private scratch path:

```
export POLICY_FOREST_STORE=.agent-output/policy-forest/store
bb --classpath nixos/otehon/storage/src:nixos/otehon/storage/vendor/apex/src:nixos/otehon/storage/vendor/apex-car/src nixos/otehon/storage/oracle/prolly_forest_policy_publish.clj
clojure -Sdeps '{:paths ["nixos/otehon/storage/src" "nixos/otehon/storage/vendor/apex/src" "nixos/otehon/storage/vendor/apex-car/src" ".agent-output/policy-forest/classpath"]}' -M nixos/otehon/storage/oracle/prolly_forest_policy.clj
```

The caller supplies trust roots, time and revocation data and maps the Dango
decision into policy capabilities. Denial in this oracle is an empty filtered
query result. This is not verified revocation distribution, a signed commit,
a signed or durable receipt, a remote product adapter, Native execution,
OS-cache loss or production authorization. Fixture encryption is identity and
blinding is synthetic; no private data or production keys are involved.
