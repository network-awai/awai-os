Only the first byte of Pack 0's 16-byte footer was overwritten with zero in the copy. The program verifies selected blocks, and this result does not prove a trusted catalog, concurrent truncation safety, a Native writer, OS-cache loss or whole-store integrity.

Local execution, with the independent copied directory as working directory: `exec 3<.; ./program.macho > stdout 2> stderr` (process status 10); `codesign --verify --strict program.macho` succeeded.
