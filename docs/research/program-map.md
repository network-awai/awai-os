# Awai Network research program map

The [research plans](research-plans.md) share one [evidence map](evidence-map.md). Workstream owners supply records and a separate reviewer performs the readback or repeat described in the [researcher profile](researcher-profile.md).

| Workstream | Agent delegation and robotics | Installation and update security | Artifact and delegation trust |
| --- | --- | --- | --- |
| OS and desktop install | `BOOT-LAN` describes the device environment. | `GPT-REFUSAL` and `INSTALL-REVIEW` supply physical audit and guard evidence. `INSTALL-PC` is open. | `BOOT-PINS` and `BOOT-INPUT` identify the evaluation inputs and qualification flags. |
| Store and catalog | `STORE-JOB` describes the app-update environment for a later task study. | `STORE-DECLARATION` supplies a refusal case. `STORE-TEXT` and `STORE-REFUSAL` document an unresolved wording conflict. | `STORE-PINS`, `STORE-BODY`, and `STORE-JOB` supply verification and staging evidence. |
| Dapps | Supply a supported reversible task, a manual baseline, and consented intervention records. | `STORE-DECLARATION` covers the Torihiki update refusal. | Supply approved broker fixtures and request-bound consent traces. |
| OTA distribution | `OTA-FEED` describes the deployed update-index environment. | `OTA-REF`, `OTA-REF-LIMIT`, `OTA-PC`, `OTA-DELTA`, and `OTA-REJECT` supply virtual-device outcomes. `OTA-ENDTOEND` is open. | `OTA-DESIGN`, `OTA-RANGE`, `OTA-ETAG`, `OTA-FEED`, `YATA-RAW`, and `YATA-CAR` supply transport evidence. |
| Fleet and bots | Supply a pinned agent workflow, task outputs, and observed operator interventions. Robotics depends on a qualified physical adapter. | Supply isolated execution fixtures for tests of actor and grant boundaries when those are in scope. | Supply matched and mismatched actor/grant traces with the owning broker. |
| Security and keys | Provide approved test credentials and the scope for participant and operator access. | `OTA-REJECT` supplies wrong-key and older-payload cases. Release custody and recovery would require separate qualification. | `STORE-PINS` supplies pointer signer checks. Supply signer provenance and revocation records for new measurements. |
| Trust | Define whose decisions and vetoes the task records must demonstrate. | Define expected authority and protected state for each refusal. | Supply the consent, publisher, and principal bindings for independent readback. `OTA-ETAG` gives a transport metadata control. |

- **Agent delegation and robotics** is EMPTY of direct evidence for labor, social, and robotics outcomes. Device and update records supply context.
- **Installation and update security** has partial evidence from audit, fixture, VM, and emulator results. Physical signed-release qualification remains open.
- **Artifact and delegation trust** has partial evidence for artifact verification and transport. Direct evidence on brokered delegation is missing from this map.
