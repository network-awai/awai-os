# Awai Drive

The Android and macOS Tauri source, build and tests are in
[network-awai/app-drive](https://github.com/network-awai/app-drive/tree/main/tauri).
The app keeps the Android package ID `network.awai.drive`.

Drive owns [the WNFS sync design](https://github.com/network-awai/app-drive/blob/main/tauri/docs/scalable-sync-design.md)
and its implementation. The previous Awai OS source remains available at
[`540674c`](https://github.com/network-awai/awai-os/tree/540674c835b67f5c2f4209627c3f589063558e7f/apps/drive).
